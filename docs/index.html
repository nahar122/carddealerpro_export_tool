Card CSV Transformer

Turns a CardDealerPro export CSV into the 5-column listing format.

This download is for macOS. You appear to be on a different platform — the binary will not run for you.
CardCSVTransformer-mac.zip · ~6.5 MB · Apple Silicon & Intel
Download for Mac

Setup (first time only)

  1. Double-click the downloaded CardCSVTransformer-mac.zip to extract it. You'll get a file called CardCSVTransformer.
  2. Double-click CardCSVTransformer. macOS will say “cannot be opened because the developer cannot be verified.” Click Cancel.
  3. Right-click CardCSVTransformer → Open → click Open in the dialog. macOS remembers this choice for future runs.

Each time you use it

  1. Double-click CardCSVTransformer. A new browser tab opens automatically.
  2. Click Choose CSV file, pick your CardDealerPro export, then Transform & download.
  3. The transformed CSV downloads automatically.
  4. Click Quit on the page when finished.
If right-click → Open doesn't work

Open Terminal (Cmd + Space → type “Terminal”) and run:

xattr -dr com.apple.quarantine ~/Downloads/CardCSVTransformer
chmod +x ~/Downloads/CardCSVTransformer

Then double-click CardCSVTransformer again.

What's actually happening

The binary starts a tiny local web server on your Mac (only your Mac — nothing leaves your machine), then opens your browser to its upload page. Your CSV is processed in memory and the result streams back as a download. When you click Quit, the server shuts down and the program exits.

It's unsigned because we don't pay Apple for a Developer ID certificate — that's why macOS warns you the first time. The right-click → Open dance is macOS's way of letting you opt in.
