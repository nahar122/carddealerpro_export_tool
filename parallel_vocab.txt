# Two sections, separated by a section header:
#   [tokens]      — words/phrases that *signal* a parallel. A run of tokens
#                   (and optional qualifiers) at the end of the subset string

#                   the trailing run for a split to happen.
#   [qualifiers]  — words/phrases that may *appear inside* a parallel run but
#                   are not enough on their own. They glue tokens together
#                   without triggering a split by themselves.

# When the heuristic guesses wrong, the fix is usually to add a missing term
# here — no Python edits needed.
